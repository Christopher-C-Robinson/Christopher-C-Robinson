College Football Index

College Football Index is a public analysis site for every FBS and FCS team. One shared model ranks the field with schedule-adjusted ratings, and conference filters change which teams you see without renumbering that full-field order.

Open live site Open source Back to projects

What it does

  • Rank FBS and FCS teams by average neutral-site win chance against the full field.
  • Browse today's games, a team season outlook, and a head-to-head matchup simulator.
  • Filter by subdivision and conference while keeping the overall ranks fixed.
  • Publish both the site and the source in public repositories.
The live site is christopher-c-robinson.github.io/college-football-index. The public repo is Christopher-C-Robinson/college-football-index.
