Macro

Macro is a desktop app for recording your own clicks and keystrokes and playing them back. It runs on Windows, Linux, and macOS, and it is built with Tauri. Playback uses human-like pointer movement, can find a click from a picture of its target, and stops on a failsafe shortcut.

Open download site Back to projects

What it does

  • Record clicks and key presses, then play them back on a clock.
  • Find a click from a picture of the screen, so a moved window can still receive it.
  • Stop playback from the Stop button or Ctrl+Shift+Escape, and release the mouse.
  • Keep each macro as a local file. Nothing in a macro is uploaded.

If macOS says the app is damaged

Clear the quarantine flag, then open Macro again:

xattr -dr com.apple.quarantine /Applications/Macro.app

Linux install

Install the Debian package, or run the AppImage:

sudo apt install ./Macro_*_amd64.deb
chmod +x Macro_*.AppImage
./Macro_*.AppImage
Installers for Apple silicon, Intel, Windows, and Linux are on the public download site. The source repository is private, so this page does not link to it.
